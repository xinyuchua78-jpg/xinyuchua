# 蔡欣渝个人品牌 Landing Page 设计说明

## 目标

将现有 AI 教育网站重构为蔡欣渝的高端个人品牌 Landing Page，参考 Purple Salon 的沉浸式全屏首屏、半透明导航、分类切换和大幅摄影语言，但不复制其商标、文案或素材。

## 品牌定位

- 姓名：蔡欣渝
- 身份：多领域成长导师 / 个人 IP
- 核心主张：让人生拥有更多可能
- 品牌理念：我教的不只是一个技能，而是让你拥有更多选择的能力。
- 四大领域：AI 智能应用、健康与美容、灵性探索、公益与社会影响力

## 页面结构

1. 全屏首屏：职业肖像、姓名、定位、主张、探索领域与联系合作按钮。
2. 四大领域标签：点击切换领域说明、服务清单与视觉主题。
3. 品牌故事：个人理念、跨领域连接方式与横向品牌介绍图。
4. 服务内容：AI 工具、内容短视频、数字人、健康美容、身心灵成长和公益项目。
5. 个人理念：成长、选择、影响力三个价值支点。
6. Blog：保留并重整现有文章入口。
7. 联系合作：无真实联系方式时使用明确的待填写位置，不虚构资料。

## 视觉系统

- 色彩：黑曜石、深紫、香槟金、柔白。
- 字体：优雅衬线标题搭配清晰无衬线正文。
- 影像：职业肖像用于首屏；横向品牌图用于领域与故事区。
- 动效：领域标签切换、轻微视差、滚动显现、按钮悬停。
- 响应式：桌面端电影感全屏；移动端聚焦人像并采用纵向卡片。

## 约束

- 纯 HTML、CSS、JavaScript，无框架和追踪脚本。
- 使用用户提供的两张图片并复制到仓库内的 `assets/`。
- 所有图片具备有意义的 `alt` 文本，交互控件可通过键盘操作。
- 未提供的资历数字、客户评价和联系方式不得虚构。
- 完成后同步到 GitHub 仓库 `xinyuchua78-jpg/xinyuchua` 的 `main` 分支并验证 GitHub Pages。
